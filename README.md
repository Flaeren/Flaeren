I program PLCs for a living and build software on the side. What I make tends to be small, calm and local-first: tools that do one job and keep your data on your machine.

## Projects

| Project | What it is |
|---|---|

| **[voidflare](https://github.com/Flaeren/voidflare)** | Offline file converters for Windows: drop a file, pick a format. Built on the ArtCraft suite. |

| **[Gabremoku Clouds](https://github.com/Flaeren/Gabremoku-Clouds)** | A volume-weighted equilibrium cloud indicator for TradingView. |
